# Simple Todo App

A beginner-friendly todo list built with plain HTML, CSS and JavaScript. No frameworks, no build step.

## Features
- Add and delete tasks
- Mark tasks as done
- Filter: All / Active / Done
- Tasks are saved in the browser (localStorage)

## Run it
Open `index.html` in your browser. That's it.

## Project structure
